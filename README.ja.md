# capture_monitor

特定のビデオキャプチャデバイスからのライブプレビューをデスクトップやブラウザに表示するシンプルなElectronアプリケーションです。

## Webデモ

ブラウザでテスト可能なWeb版はこちらからアクセスできます:

[https://code4fukui.github.io/capture_monitor/](https://code4fukui.github.io/capture_monitor/)

## 仕組み

このユーティリティは、特定のビデオソース用のシンプルで無駄のないモニターとして機能するように設計されています。名前に「capture」という単語が含まれる接続済みのビデオ入力デバイス（例: 「USB Capture」、「HDMI Capture」）を自動的に検索し、そのデバイスからの映像をウィンドウ全体に表示します。

以下の用途に最適です:
- HDMIキャプチャカードを経由したゲーム機や別PCの出力のモニタリング。
- 一眼レフやミラーレスカメラを高画質なWebカメラとして使用する際の、クリーンなプレビュー表示。
- 多機能なメディアプレイヤーのような煩雑なUIなしに、特定のビデオ入力専用のディスプレイが必要なあらゆる場面。

## 機能

- **デバイスの自動検出:** デバイス名に「capture」が含まれるデバイスを自動的に見つけて映像を表示します。
- **クロスプラットフォーム:** Electronを使用し、Windows、macOS、Linux上でスタンドアロンのデスクトップアプリケーションとして動作します。
- **ミニマルなインターフェース:** ウィンドウには映像のみが表示され、枠やコントロールパネルはありません。
- **Web版デモ:** 対応ブラウザ上で直接実行することも可能です。

## はじめに（デスクトップアプリケーション）

### 前提条件

- [Node.js](https://nodejs.org/en/)（最新バージョンを推奨）

### インストールと使用方法

1. リポジトリをクローンします:
    ```sh
    git clone https://github.com/code4fukui/capture_monitor.git
    cd capture_monitor
    ```
2. 依存関係をインストールします:
    ```sh
    npm install
    ```
3. アプリケーションを実行します:
    ```sh
    npm start
    ```

## ビルド

お使いのOS向けの配布可能なスタンドアロンアプリケーションを作成するには、ビルドスクリプトを実行します。これにより `electron-packager` が実行され、新しいフォルダ（例: `capture_monitor-win32-x64`）にアプリケーションが生成されます。

```sh
npm run build
```

## カスタマイズ

アプリケーションの動作は簡単に変更できます:

- **フルスクリーン / キオスクモード:** `main.js` 内の `kiosk: true` の行のコメントアウトを解除すると、枠のないフルスクリーンモードでアプリが起動します。
- **映像のミラーリング（左右反転）:** `index.css` 内の `-webkit-transform: scaleX(-1);` の行のコメントアウトを解除すると、映像が左右反転して表示されます。
- **ターゲット解像度の変更:** `index.html` 内の `width` と `height` の値を変更することで、デバイスに要求する解像度を変更できます。
